土庫消防隊｜台78線救災快速判別系統　手機版套件（可安裝、可離線）
==============================================================

這個資料夾的內容放到「網站空間」後，用手機開啟並加入主畫面，就像 App 一樣使用，
而且在有網路的地方開啟過一次後，之後沒有網路也能判別。

檔案：index.html（程式）、manifest.webmanifest（App 資訊）、sw.js（離線快取）、icon-*.png（圖示）
請把這 7 個檔案一起上傳，不要少任何一個。

【一、免費放到網路（GitHub Pages）】
  1. 註冊免費 GitHub 帳號（github.com），右上角「＋」→ New repository，名稱例如 tk78，按 Create。
  2. 在新儲存庫頁面按「uploading an existing file」，把這 7 個檔案全部拖進去，按 Commit changes。
  3. 上方 Settings → 左側 Pages → Source 選「Deploy from a branch」，Branch 選 main、資料夾 /(root)，按 Save。
  4. 等 1～3 分鐘，頁面上會出現網址：https://你的帳號.github.io/tk78/
  ※ 儲存庫若設為公開，任何人都看得到規則內容；請先確認隊上同意。
  ※ 也可改用 Cloudflare Pages 等其他免費靜態網站服務，步驟相同：上傳這 7 個檔案即可。

【二、加入手機主畫面】
  iPhone：用 Safari 開啟網址 → 下方「分享」→「加入主畫面」→「新增」。
  Android：用 Chrome 開啟網址 → 右上角「⋮」→「安裝應用程式」（或「加到主畫面」）。
  之後從主畫面圖示「台78判別」開啟，沒有網址列，全螢幕使用。

【三、確認離線可用（請務必做一次）】
  1. 在有網路時，從主畫面圖示開啟一次，等畫面出現後稍等幾秒。
  2. 關閉 App，手機開啟飛航模式。
  3. 再從主畫面圖示開啟，輸入「東行 24.6」按「立即判別」，應顯示「土庫交流道」。
  若離線打不開，請重新在有網路時開啟並稍等，或移除圖示後重新加入主畫面。

【四、手機輸入】
  公里數預設跳出數字鍵盤，直接輸入 24.6 即可。
  要輸入 K 或 + （例如 24K+600）時，按輸入框右邊的「ABC」切換成全鍵盤，再按「123」可切回。

【五、規則資料與備份】
  - 在「規則」頁修改的內容，只存在這支手機的瀏覽器／App 裡，不會同步到其他手機。
  - 每次修改後，請按「複製 JSON」貼到備忘錄或 LINE 保存（手機上「匯出 JSON」下載鈕不一定能用）。
  - 其他手機要更新規則：把 JSON 存成 .json 檔後，用「匯入 JSON」選取。
  - 清除瀏覽器資料、移除 App 可能會清掉本機規則。

【六、更新程式或規則版本】
  把新版檔案覆蓋上傳到同一個儲存庫（取代舊檔），手機在有網路時開啟 App 即會在背景更新，
  「再開一次」就是新版。若要確定換新，可把 sw.js 第 2 行的版本字串（tk78-v1.5.0）改成新的數字再上傳。

【七、限制】
  - 不具即時交通、封路、GPS 定位功能。
  - 手機無法做出桌面版那種「浮在其他 App 上方」的視窗。
  - iPhone 長期未使用，系統可能清除 App 的離線資料；重要時請先開啟一次確認。

※ 勤務輔助工具，仍須依正式勤務規定執行。
